# Personal Portfolio

A modern, responsive portfolio website showcasing my professional experience, skills, and educational background as a Data Scientist specializing in healthcare AI.

## Live Demo

Visit the live portfolio: [Shruti Naik Portfolio](https://professional-portfolio-shrutinaik.replit.app/)

## Features

- **Clean, Minimalist Design** - Professional aesthetic with focused content presentation
- **Responsive Layout** - Fully optimized for all device sizes (mobile, tablet, desktop)
- **Interactive Elements** - Smooth scrolling, animations, and transitions using Framer Motion
- **Accessible UI Components** - Built with shadcn/ui and Radix UI primitives
- **Contact Form** - Functional form for visitor inquiries

## Technologies Used

- **Frontend Framework**: React + TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui (based on Radix UI)
- **Animations**: Framer Motion
- **Form Handling**: React Hook Form + Zod validation
- **Icons**: Lucide React

## Sections

- **Hero** - Introduction with professional image and tagline
- **About** - Professional summary and technologies
- **Experience** - Work history with detailed responsibilities
- **Skills** - Technical expertise with proficiency indicators
- **Education** - Academic background and qualifications
- **Contact** - Contact information and message form

## Development

This project was created using Vibe Coding on Replit, a powerful AI-assisted coding platform that helped streamline the development process from initial concept to final deployment.

## Setup Instructions

If you want to run this project locally:

1. Clone the repository
2. Install dependencies with `npm install`
3. Run the development server with `npm run dev`
4. Open your browser at `http://localhost:5000`
